ABOUT

From Windows 3.1 to cloud and identity engineering.

I’ve been fascinated by technology since my dad brought home a Compaq desktop PC running Windows 3.1 when I was a kid. He put it in my bedroom. He showed me how to boot into Windows from the DOS command line. It was so interesting to me that he somehow just knew how to do this. I remember him carrying around one of those unmistakable 1990s IBM ThinkPads. That early exposure stuck with me, and I’ve been curious about computers and how systems work ever since.

Today I’m an infrastructure engineer working across Microsoft cloud, identity, and security technologies. My work includes Microsoft Entra ID, identity governance, authentication, Azure infrastructure, automation, and large-scale Microsoft enterprise environments.

I especially enjoy solving complex cross-service problems and building repeatable solutions with PowerShell, Microsoft Graph, Terraform, Python, Azure DevOps, GitLab, and GitHub Actions. My current focus is cloud security engineering, identity architecture, detection engineering, and secure infrastructure automation.
